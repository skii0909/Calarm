# Work Alarm V1.3 알람 제어·공휴일·Night Pulse 디자인 설계

## 목표

알람마다 공휴일 자동 건너뛰기, 1분 점증 볼륨, 5~30분 다시 울림 설정을 제공한다. 서버나 외부 API 없이 대한민국 공휴일과 저작권 안전 추천 사운드를 앱에 포함하고, 목록과 편집 화면을 `Night Pulse` 디자인으로 개선한다.

기존 V1.2의 캘린더 제목 키워드 건너뛰기, 22시 다음 날 변화 안내, 실제 알람 시각 최종 확인은 유지한다.

## 성공 기준

- 알람별로 공휴일 자동 건너뛰기를 켜고 끌 수 있다.
- 2026~2031년 대한민국 법정·대체공휴일을 서버 없이 판정한다.
- 연결된 Google Calendar 일정으로 임시공휴일을 보완한다.
- 공휴일로 다음 날 알람 상태가 바뀌면 22시에 공휴일 이름을 포함한 시스템 알림을 소리와 진동으로 한 번 보낸다.
- 실제 알람 시각에도 공휴일과 캘린더를 최종 확인한다.
- 알람별로 1분 점증 볼륨을 켜고 끌 수 있다.
- 알람별 다시 울림 시간을 5~30분 범위에서 1분 단위로 선택한다.
- 시스템 알람음과 앱 내 추천 사운드 중 하나를 선택하고 미리 들을 수 있다.
- 추천 사운드는 앱이 직접 제작한 음원만 사용하며 APK 업데이트 때 갱신한다.
- 앱 목록과 알람 편집 화면은 선택된 `Night Pulse` 시각 체계를 사용한다.
- V1.2 데이터와 기능이 손실 없이 유지된다.

## 데이터 모델 및 마이그레이션

`Alarm`에 다음 값을 추가한다.

```kotlin
val skipOnPublicHoliday: Boolean = false
val gradualVolume: Boolean = false
val snoozeMinutes: Int = 5
```

기존 `ringtoneUri`는 시스템 URI와 앱 추천 사운드 URI를 모두 저장한다. 앱 추천 사운드는 안정적인 `android.resource://<package>/<resourceId>` URI로 표현한다.

Room 3→4는 `alarms`에 다음 컬럼을 추가한다.

```sql
ALTER TABLE alarms ADD COLUMN skip_on_public_holiday INTEGER NOT NULL DEFAULT 0;
ALTER TABLE alarms ADD COLUMN gradual_volume INTEGER NOT NULL DEFAULT 0;
ALTER TABLE alarms ADD COLUMN snooze_minutes INTEGER NOT NULL DEFAULT 5;
```

기존 알람은 공휴일 건너뛰기와 점증 볼륨이 꺼지고 다시 울림은 5분으로 유지된다. `snooze_minutes`는 저장 전에 5~30 범위를 검증한다.

## 대한민국 공휴일

### 앱 내 데이터

2026년 1월 1일부터 2031년 12월 31일까지 공식 법정공휴일, 대체공휴일, 데이터 확정 시점에 공표된 임시공휴일과 선거일을 날짜·표시명으로 앱에 포함한다.

```kotlin
data class PublicHoliday(val date: LocalDate, val name: String)
```

`KoreanPublicHolidayProvider.find(date)`는 해당 기간의 휴일을 반환한다. 서버와 네트워크를 사용하지 않는다.

### 캘린더 보완

연결된 Google Calendar의 해당 날짜 일정 제목도 검사한다. 앱 내 공휴일 데이터에 없는 일정이라도 제목이 `임시공휴일`, `선거일`, `대한민국 공휴일` 또는 알려진 공휴일 이름 규칙과 일치하면 공휴일 사유로 보완한다. 일반 개인 일정은 기존 알람별 키워드 규칙으로만 처리한다.

앱 내 데이터가 우선이며, 같은 휴일이 캘린더에도 있으면 중복 이유를 제거한다. 캘린더 권한 없음과 조회 실패는 앱 내 데이터 판정에 영향을 주지 않는다.

### 지원 기간 밖

2032년 이후에는 앱 내 공휴일 판정을 수행하지 않는다. 설정/도움말에 `공휴일 데이터 업데이트가 필요합니다`를 표시한다. 연결 캘린더에 명확한 공휴일 일정이 있으면 보완 판정은 계속 사용할 수 있지만, 완전성을 보장하지 않는다.

## 알람 판정 순서

알람 실행 시 다음 순서로 판단한다.

1. 알람 활성화와 반복 요일 확인
2. `skipOnPublicHoliday`가 켜져 있으면 앱 내 공휴일과 캘린더 공휴일 확인
3. `skipOnCalendarMatch`가 켜져 있으면 알람별 제목 키워드 확인
4. 하나 이상의 건너뛰기 이유가 있으면 해당 날짜의 실행만 건너뜀
5. 권한 또는 캘린더 조회 실패만 발생하면 fail-open으로 알람을 울림

공휴일과 키워드 일정이 동시에 일치하면 두 이유를 모두 결과에 포함한다. 알람의 `enabled` 값은 변경하지 않는다.

## 22시 다음 날 변화 알림

V1.2의 `RING`/`SKIP` 비교를 유지하면서 `SKIP` 사유 목록을 저장한다.

공휴일로 `RING → SKIP`이 되면:

```text
제목: 내일 알람이 쉽니다
내용: 광복절로 인해 오전 07:00 ‘출근 알람’이 울리지 않습니다.
```

공휴일과 캘린더 키워드가 함께 일치하면:

```text
광복절 및 ‘휴가’ 일정으로 인해 오전 07:00 ‘출근 알람’이 울리지 않습니다.
```

`SKIP → RING`이면 기존처럼 다시 울린다고 안내한다. 변화가 없으면 알림을 보내지 않는다. `next_day_alarm_changes` 채널은 기본 알림음과 진동을 활성화하며 사용자가 Android 설정에서 채널 동작을 변경할 수 있다.

22시 이후에는 추가 상태 알림을 보내지 않고 실제 알람 시각에 최신 캘린더와 공휴일을 다시 확인한다.

## 점점 크게 울리기

`gradualVolume`이 꺼져 있으면 현재처럼 즉시 정상 재생 볼륨으로 시작한다.

켜져 있으면 `MediaPlayer.setVolume()`만 사용한다.

- 시작 재생 볼륨: `0.05f`
- 증가 시간: 60초
- 갱신 간격: 1초
- 60번째 단계에서 `1.0f`
- 좌우 채널에 같은 값을 적용

시스템 알람 볼륨 자체는 변경하지 않는다. 해제, 다시 울림, 서비스 종료, 재생 실패 시 볼륨 증가 coroutine/job을 즉시 취소한다. 음원 fallback이 발생해도 동일한 규칙을 적용한다.

## 다시 울림 시간

알람 편집 화면에서 5~30분을 1분 단위로 선택한다.

- 기본값: 5분
- `–`와 `+` 버튼
- 현재 값을 큰 숫자로 표시
- 5분에서 감소, 30분에서 증가는 비활성화
- 자유 텍스트 숫자 입력은 사용하지 않음

알람 울림 화면의 `다시 알림`은 현재 알람의 `snoozeMinutes`를 사용한다. 스누즈 전달은 반복 알람을 추가로 예약하지 않고 한 번만 실행한다.

## 추천 사운드

추천 사운드는 APK의 `res/raw`에 포함한다. 초기 목록은 다음 6개 앱 전용 오리지널 음원이다.

- Sunrise Pop
- Soft Marimba
- Digital Pulse
- Lo-fi Bell
- Bright Chime
- Minimal Beat

음원은 앱을 위해 직접 생성하며 외부 음원을 샘플링하지 않는다. SNS·숏폼은 템포, 악기 구성, 분위기 참고에만 사용한다. 각 음원의 메타데이터에 제작 방식과 앱 전용 원본임을 기록한다.

추천 사운드 선택 화면은 다음을 제공한다.

- 사운드 이름과 분위기 설명
- 한 번에 하나만 재생되는 미리 듣기/중지
- 선택 및 취소
- 시스템 알람음 선택 화면으로 이동

새 추천 사운드는 APK 버전 업데이트 때 추가한다. 인터넷 권한, 다운로드, 서버 저장소는 추가하지 않는다. 선택한 추천 사운드 리소스를 새 버전에서도 삭제하지 않아 기존 알람 URI가 깨지지 않게 한다.

## Night Pulse 디자인

현재 아이콘은 유지한다. 앱 본문은 선택된 B안의 다크 디자인을 적용한다.

### 시각 체계

- 배경: 짙은 네이비
- 강조: 보라색→하늘색 그라데이션
- 카드: 배경보다 밝은 네이비와 얇은 경계선
- 주요 텍스트: 흰색
- 보조 텍스트: 연한 청회색
- 상태 칩: 공휴일, 캘린더, 점점 크게, 다시 울림 시간

다크 색상에서도 Material 접근성 대비를 지키고, 오류와 비활성 상태는 색상뿐 아니라 문구와 아이콘으로 함께 표현한다.

### 알람 목록

- 상단 `WORK ALARM`과 설정 버튼
- 가장 가까운 알람을 큰 그라데이션 카드로 표시
- 남은 시간을 보조 문구로 표시
- 나머지 알람은 개별 카드
- 각 카드에 시간, 이름, 반복 요일, 활성 스위치, 기능 상태 칩
- 하단의 큰 `새 알람` 버튼

### 알람 편집

화면 전체를 스크롤 가능하게 하고 설정을 카드로 나눈다.

1. 알람 이름과 시간
2. 반복 요일과 활성화
3. 쉬는 날: 공휴일 및 캘린더
4. 소리: 시스템/추천 사운드와 점증 볼륨
5. 다시 울림 시간
6. 저장 및 삭제

## 설정 및 도움말

다음 내용을 추가한다.

- 공휴일 자동 건너뛰기 적용 범위
- 내장 공휴일 데이터 지원 기간 2026~2031
- 임시공휴일은 연결 캘린더로 보완하며 누락될 수 있다는 안내
- 점점 크게는 시스템 볼륨을 변경하지 않는다는 안내
- 다시 울림 5~30분 설정 방법
- 추천 사운드는 앱 전용 음원이며 APK 업데이트 때 갱신된다는 안내

## 오류 처리

- 공휴일 데이터 범위 밖: 내장 판정 없음, 도움말 경고 표시
- 캘린더 권한 없음/조회 실패: 앱 내 공휴일 판정은 계속 적용
- 추천 사운드 재생 실패: 시스템 기본 알람음으로 fallback
- 미리 듣기 중 화면 이탈: 플레이어 즉시 정리
- 볼륨 증가 중 서비스 종료: 증가 작업 취소 후 플레이어 해제
- 잘못된 다시 울림 값: 저장 거부 또는 5~30 범위로 정규화

## 완료 조건

- V1.2 데이터와 기능을 유지하는 업데이트 APK가 생성된다.
- 공휴일 옵션이 켜진 알람만 공식 휴일에 건너뛴다.
- 22시 변화 알림에 정확한 공휴일 사유가 표시되고 소리·진동이 작동한다.
- 점증 볼륨과 알람별 다시 울림 시간이 실제 서비스에 적용된다.
- 추천 사운드 6개를 미리 듣고 선택할 수 있다.
- 목록과 편집 화면이 Night Pulse 디자인으로 표시된다.
- 서버, 외부 API, 음원 다운로드 없이 동작한다.
- lint, 단위 테스트, Android 테스트 컴파일, APK 빌드가 성공한다.
