# 필수 권한·캘린더 선택·도움말 개편 설계

## 목표

Work Alarm이 동작에 필요한 권한을 앱 실행 때마다 스스로 점검하고, 사용자가 여러 Google 계정과 캘린더 중 실제 알람 판단에 사용할 캘린더를 선택할 수 있게 한다. 설정/도움말 화면은 현재 Night Pulse 디자인에 맞게 재구성한다.

## 범위

- 필수 권한 통합 점검 및 반복 안내
- Google 계정별 캘린더 표시와 캘린더 단위 선택
- 선택한 캘린더만 모든 일정 판단에 사용
- 설정/도움말 화면의 카드형 재설계와 내용 정리
- 기존 설치 사용자의 안전한 초기 선택 마이그레이션

Outlook 연동, Google API/OAuth, 외부 서버, 계정 추가/삭제 자체는 이번 범위에 포함하지 않는다. 휴대폰의 Android Calendar Provider에 동기화된 Google 캘린더만 사용한다.

## 필수 권한 흐름

앱 시작 시 다음 항목을 순서대로 검사한다.

1. 캘린더 읽기 권한
2. 알림 권한(Android 13 이상)
3. 정확한 알람 예약 권한(Android 12 이상에서 필요 시)
4. 전체화면 알람 권한(Android 14 이상)

누락된 항목이 있으면 하나의 통합 안내 다이얼로그에 현재 누락 목록을 표시한다. `설정하기`는 현재 처리할 첫 항목의 런타임 권한 요청 또는 정확한 시스템 설정 화면으로 연결한다. 사용자가 돌아오면 전체 상태를 다시 검사하고 다음 누락 항목을 안내한다.

사용자가 `나중에`를 누르면 현재 앱 실행 중에는 닫을 수 있지만, 앱을 완전히 나갔다가 다시 실행하면 권한이 모두 충족될 때까지 다시 표시한다. 이미 허용된 항목과 해당 Android 버전에 존재하지 않는 권한은 요청하지 않는다.

설정/도움말 화면에도 각 권한의 현재 상태와 개별 설정 버튼을 제공한다.

## 캘린더 발견 모델

Calendar Provider에서 다음 정보를 읽는다.

- 캘린더 ID
- 캘린더 표시 이름
- 계정 이름(예: 이메일 주소)
- 계정 유형
- 표시 및 이벤트 동기화 가능 여부

V1 선택 대상은 `ACCOUNT_TYPE = com.google`, `VISIBLE = 1`, `SYNC_EVENTS = 1`인 캘린더다. 계정 이름으로 그룹화하되 실제 선택과 조회는 캘린더 ID 단위로 수행한다.

## 선택 상태와 초기화

선택 상태는 기기 내부에만 저장하며 서버를 사용하지 않는다.

- 첫 설치 또는 이 기능으로 처음 업그레이드한 시점에는 발견된 Google 캘린더를 모두 선택한다.
- 사용자가 선택을 변경한 뒤에는 그 선택을 유지한다.
- 새 Google 캘린더가 이후 기기에 추가되면 안전한 기존 동작을 유지하기 위해 기본 선택한다.
- 기기에서 사라진 캘린더 ID는 저장 상태에서 정리한다.
- 선택된 캘린더가 하나도 없으면 캘린더 미연결 상태로 취급하고 앱 실행 및 알람 생성/수정 시 선택 안내를 표시한다.

계정 체크박스는 해당 계정 아래 캘린더 전체를 선택/해제하는 일괄 조작이다. 계정이 일부만 선택된 경우 중간 선택 상태를 표시한다. 사용자는 계정을 펼쳐 캘린더 하나씩 선택할 수 있다.

## 일정 조회 적용

현재 모든 Google 캘린더 ID를 직접 조회하는 경로를 선택 저장소에서 제공하는 캘린더 ID 조회로 교체한다. 다음 기능은 반드시 같은 선택 결과를 사용한다.

- 일반 알람의 키워드 기반 건너뛰기
- 휴가 일정 판단
- 공휴일 캘린더 보완
- 교대근무 제목 정확 일치
- 실제 알람 시각의 최종 확인
- 매일 22시 다음 날 상태 확인 및 변경 알림
- 교대근무 다음 알람 미리보기

선택된 캘린더가 없거나 Calendar Provider 조회에 실패하면 기존 안전 정책을 유지한다. 일반 알람은 울리고, 교대 그룹은 지정된 비상 기본 근무 알람만 울리며, 22시에는 필요한 경고를 보낸다.

## 설정/도움말 UI

긴 텍스트 목록을 Night Pulse 카드 구조로 교체한다.

### 연결 및 권한

필수 권한별 상태 칩과 설정 버튼을 표시한다. 모두 정상일 때는 `알람 실행 준비 완료` 상태를 보여준다.

### 사용 중인 캘린더

Google 계정별 카드를 표시한다. 카드 헤더에는 계정 이름, 선택된 캘린더 수, 전체 선택 체크박스, 펼치기 버튼을 둔다. 펼치면 캘린더 표시 이름과 개별 체크박스가 나온다. 변경은 즉시 로컬에 저장하고 이후 조회부터 적용한다.

### 사용법 카드

아래 주제로 내용을 분리한다.

- 일반 반복 알람과 해제/다시 울림
- 캘린더 키워드 자동 건너뛰기와 쉼표 입력
- 제목 전체 일치를 사용하는 교대근무 그룹
- 22시 변경 알림과 실제 알람 시각 최종 확인
- 공휴일 자동 끄기
- 알람음과 점점 크게
- 캘린더 조회 실패 시 안전 동작

각 카드는 제목과 짧은 요약을 먼저 보여주고, 필요한 경우 펼쳐 상세 내용을 읽도록 한다.

## 구조

- `RequiredPermissionsCoordinator`: OS 버전과 현재 권한을 바탕으로 누락 항목과 이동 Intent를 제공한다.
- `CalendarCatalogRepository`: 계정 정보가 포함된 읽기 가능한 Google 캘린더 목록을 제공한다.
- `CalendarSelectionRepository`: 최초 전체 선택, 선택 저장, 새 항목 기본 선택, 사라진 항목 정리를 담당한다.
- `CalendarContractEventSource`: 선택된 캘린더 ID만 받아 이벤트를 조회한다.
- `SettingsViewModel`: 권한 상태, 계정별 캘린더, 선택 상태, 도움말 UI 상태를 제공한다.

간단한 로컬 선택 값에는 SharedPreferences를 사용한다. 별도의 Room 마이그레이션이나 서버는 추가하지 않는다.

## 오류 처리

- 권한 설정 Intent를 열 수 없는 예외 상황에서는 앱 상세 설정 화면으로 대체 이동한다.
- 캘린더 목록 조회 실패는 빈 목록과 구분되는 실패 상태로 UI에 표시한다.
- 캘린더가 동기화 중 변경되어 저장 ID와 달라져도 조회 시 목록을 재조정한다.
- 선택 저장 실패 시 이전 선택을 유지하고 사용자에게 변경 실패 메시지를 표시한다.
