## 시나리오

- [ ] 월~금 07:00 알람이 휴가가 아닌 선택 요일에 울린다.
- [ ] `휴가 일정에는 이 알람 건너뛰기`가 꺼진 두 번째 알람은 휴가 중에도 울린다.
- [ ] 하루 종일 하루짜리 `휴가` 일정은 옵션이 켜진 알람만 당일에 건너뛴다.
- [ ] 여러 날 `여름휴가` 일정은 포함된 모든 날짜를 건너뛰고 종료 후 다시 울린다.
- [ ] 알람 직전에 추가한 휴가 일정이 반영된다.
- [ ] 알람 직전에 삭제한 휴가 일정은 알람을 허용한다.
- [ ] 캘린더 권한을 취소하면 fail-open 정책에 따라 알람이 울린다.
- [ ] 화면 켜짐, 화면 꺼짐, 잠금 화면에서 알람이 표시된다.
- [ ] 해제하면 소리와 진동이 중지된다.
- [ ] 다시 알림은 5분 후 한 번 울린다.
- [ ] 화면이 꺼지고 기기가 잠긴 상태에서 알람이 화면을 깨우고 잠금 화면 위에 제어 화면을 표시한다.
- [ ] 기기가 잠금 해제된 상태에서 알람 제어 화면이 즉시 표시되거나 Android가 지원하는 알람 전체화면/헤드업 방식으로 표시된다.
- [ ] `알람 해제`는 현재 울리는 발생의 소리·진동만 중지하고, 다음 일반 반복 알람은 계속 예약되어 있다.
- [ ] 설정한 다시 울림 지연(5~30분) 뒤에 다시 울리고 동일한 제어 화면이 표시된다.
- [ ] 재부팅 후 활성 알람이 복구된다.
- [ ] 시스템 시각 또는 시간대 변경 후 다음 실행이 다시 계산된다.
- [ ] 정확한 알람 권한을 나중에 허용하면 활성 알람이 자동으로 재예약된다.
- [ ] V1.4.1 위에 V1.5를 설치해도 기존 일반 알람의 이름, 시간, 반복 요일, 활성화 상태와 휴가·공휴일 건너뛰기 설정이 유지된다.
- [ ] 실제 기기 또는 에뮬레이터에서 Room 4→5 마이그레이션 계측 테스트가 통과하고, 기존 일반 알람이 삭제되지 않는다.
- [ ] 시간 선택창에서 05:00 등 원하는 시각을 정확히 선택하고 저장할 수 있다.
- [ ] 알람마다 쉼표로 구분한 서로 다른 키워드를 저장할 수 있다.
- [ ] 키워드가 일정 제목의 앞·중간·뒤에 포함되어도 해당 알람만 건너뛴다.
- [ ] 키워드가 비어 있으면 캘린더 일정 때문에 알람을 건너뛰지 않는다.
- [ ] 시스템 알람음 선택창에서 알람별 소리를 선택하고 다시 편집해도 선택이 유지된다.
- [ ] 선택한 알람음을 재생할 수 없으면 시스템 기본 알람음으로 울린다.
- [ ] 22시에 다음 날 알람이 `울림 → 건너뜀`으로 바뀌면 일반 시스템 알림이 한 번 표시된다.
- [ ] 다음 반복일에 `건너뜀 → 울림`으로 복귀하면 22시에 복귀 알림이 표시된다.
- [ ] 다음 날 상태가 같으면 22시 시스템 알림이 표시되지 않는다.
- [ ] 22시 이후 캘린더 변경은 추가 알림 없이 실제 알람 시각의 최종 판정에 반영된다.
- [ ] 캘린더가 0개이면 앱 시작, 알람 추가, 알람 수정 때마다 연결 팝업이 표시된다.
- [ ] Google Calendar가 하나 이상 연결되면 연결 팝업이 표시되지 않는다.
- [ ] 설정 화면에서 연결 캘린더와 사용법/도움말을 확인할 수 있다.
- [ ] Android 14에서 전체화면 알람 접근을 거부한 뒤 앱 내 안내를 통해 허용하면 상태가 갱신된다.
- [ ] 캘린더, 알림, 정확한 알람, 전체화면 알람 권한을 각각 거부·허용할 수 있고 누락 항목은 새 앱 실행 시 다시 안내된다.
- [ ] Google 계정 4개가 각각 그룹으로 표시되고, 펼치기/접기, 일부 선택 상태, 개별 캘린더 선택, 계정 전체 선택을 확인한다.
- [ ] 선택한 캘린더만 일반 알람 건너뛰기, 휴가, 교대근무 일치, 실제 시각 최종 확인, 22:00 미리보기에 반영된다.
- [ ] Calendar Provider 읽기 실패 시 선택 상태가 유지되고 기존 안전 fallback 정책이 적용된다.
- [ ] Compose 교대 그룹 화면에서 `교대 알람 그룹`, `오늘 근무`, `비상 기본 알람`, `정확히 일치할 캘린더 제목`을 확인하고 그룹·근무 형태를 추가·편집·삭제할 수 있다.
- [ ] 제목이 정확히 `야간`인 일정은 야간 알람을 선택하고, `야간 근무 후 회식`처럼 부분적으로만 일치하는 제목은 어떤 근무 형태도 선택하지 않는다.
- [ ] 주간 일정이 있던 다음 날을 야간 일정으로 바꾸면 22시에 한 번만 근무 변경 안내가 표시되고 야간 알람만 예약된다.
- [ ] 야간 일정이 이틀 연속이면 두 번째 22시에는 근무 변경 안내가 표시되지 않는다.
- [ ] 등록된 근무 형태가 없는 날에는 해당 교대 그룹의 모든 알람이 울리지 않고 일반 알람은 정상 동작한다.
- [ ] 같은 날짜에 주간과 야간 일정이 함께 있으면 충돌 안내가 표시되고 해당 교대 그룹 알람은 모두 울리지 않는다.
- [ ] 캘린더 권한을 취소하거나 조회 오류를 유발하면 지정한 비상 기본 근무 형태 알람만 울리고, 비상 기본 알람이 없으면 교대 그룹 알람은 울리지 않는다.
- [ ] 22시 이후 주간·야간 일정이나 근무 없음 상태를 바꿔도 추가 안내는 없고, 실제 알람 시각의 재조회 결과에 따라 선택·건너뜀·비상 기본 알람이 적용된다.
- [ ] 재부팅, 시스템 시각 변경, 시간대 변경, 앱 업데이트 후에도 활성 교대 근무 형태의 다음 알람이 다시 예약된다.

## 현재 자동 검증 범위

- 순수 Kotlin 날짜·반복 요일 계산
- 알람별 일정 제목 키워드 매칭과 캘린더 오류 fail-open
- 알람음 선택 URI 전달과 기본 알람음 대체 순서
- Room 매퍼와 DAO, 4→5 마이그레이션 계측 테스트 컴파일(실제 기기/에뮬레이터 실행은 별도)
- 저장·활성화·삭제와 AlarmManager 예약 조정
- 알람 실행 순서와 휴가 스킵
- 활성 알람 재예약
- 알람 편집 상태 검증
- 온보딩·시간 선택·교대 그룹 Compose UI 및 Room 마이그레이션 계측 테스트 컴파일
