## 실기기 확인

- [ ] 잠금 상태·화면 꺼짐 상태에서 정확한 시각에 전체화면 알람이 나타난다.
- [ ] 최근 앱에서 제거한 뒤에도 소리와 진동을 포함해 알람이 나타난다.
- [ ] 중앙 원을 왼쪽·오른쪽·위·아래·대각선으로 임계값 이상 밀면 해제된다.
- [ ] 짧게 밀면 원이 중앙으로 돌아가고 알람은 계속 울린다.
- [ ] 다시 울림 사용 알람은 3초간 길게 누르면 설정된 분 뒤 동일한 화면으로 다시 울린다.
- [ ] 다시 울림을 끈 알람에는 길게 누르기 영역이 나타나지 않는다.
- [ ] 긴 알람 제목이 최대 두 줄 안에서 축소되며 해제 영역과 겹치지 않는다.
- [ ] 알림·정확한 알람·전체화면 알람 권한을 각각 끄면 진단 카드가 `확인 필요`로 표시한다.
- [ ] 배터리 최적화가 적용되면 진단 카드가 경고하고 공개 시스템 설정으로 이동한다.
- [ ] 재부팅·시간 변경·시간대 변경 후 일반 및 교대 알람이 다시 예약된다.
- [ ] 휴가 일정, 공휴일, 교대 제목 매칭, 22시 변경 알림이 기존 규칙대로 작동한다.
- [ ] TalkBack 접근성 클릭으로 알람을 해제할 수 있다.
- [ ] 애니메이션 사용 안 함 설정에서도 3초 다시 울림 진행률이 실제 시간과 일치한다.
